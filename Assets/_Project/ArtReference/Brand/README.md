# CRASHVERSE wordmark (official, v1)
Original art, built in PIL by `make_wordmark.py` (Lilita One, OFL). It isn't traced from any reference.
- `crashverse_wordmark.png`: 2048px wide, transparent. Use this master.
- `crashverse_wordmark_1024.png` and `crashverse_wordmark_512.png`: downscaled versions.
- `crashverse_wordmark_mono_white.png` and `crashverse_wordmark_mono_navy.png`: single-colour silhouettes, for watermarks and one-colour print.
- `wordmark_preview_on_navy_and_sky.png`: legibility check.

Colours: CRASH is a gradient from #FFE45C to #FF8A12, and VERSE runs from #56DEFF to #9258FA. The rim is a gold gradient from #FFECA0 to #B0701E. The extrusion and outline are navy #161A3E, with a soft drop shadow underneath.
Clear space: keep at least the height of one letter "C" × 0.25 clear on all sides. The minimum width is 360px. Don't recolour it, stretch it or add effects.
