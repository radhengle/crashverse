# CRASHVERSE

Android 3D destruction puzzle game (Unity 2022.3.50f1 LTS + URP 14). Chapter 1 "Sunnyville Isles" (L1–10, Tidewarden boss),
6 power-ups (Core/Module/Booster), Emberforge Daily Titan, 7-day rewards, 4-week season, leaderboards, cosmetic store.

- Build: see BUILD.md (GameCI APK from GitHub Actions, or local Unity).
- QA: see QA_NOTES.md (test clock, offline toggle, ticket IDs fixed).
- Content is data-driven: `Assets/_Project/Resources/Data/*.json`, regenerated by `Tools/ContentGen/gen_content.py`.
- Live-ops sit behind `IBackendService`; `LocalBackendService` is the offline stub (fake leaderboard, test clock).
- Logic tests (no Unity needed): `dotnet run --project Tools/Tests` (61 cases). Compile check against Unity stubs: `dotnet build Tools/CompileCheck`.

- **Saves (BUG-18):** Saves from builds before 40f5286 (`local_server_db.json`, `campaign_save.json`, queue/journal files) are **unsupported**: there is no migration. Clear app data (or reinstall) when upgrading test devices.
